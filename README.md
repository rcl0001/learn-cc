# Learning & Insight Repository

> 知识笔记与学习记录的数字花园

## 结构说明

```
.
├── notes/           # 主题笔记（按领域分类）
│   ├── programming/ # 编程相关
│   ├── languages/   # 语言学习
│   ├── concepts/    # 抽象概念
│   └── book-notes/  # 读书笔记
├── journals/        # 时间线日志
│   └── 2026/
│       ├── 04-april/
│       └── 05-may/
├── references/      # 参考资料收集
├── templates/       # 笔记模板
├── attachments/     # 图片、文件等附件
└── insights.md      # 核心洞察总览
```

## 使用方式

1. **日常记录**：在 `journals/YYYY/MM-month/` 中按日期创建日志
2. **主题整理**：在 `notes/` 相应分类下建立主题笔记
3. **链接引用**：使用Markdown链接连接相关笔记
4. **版本控制**：所有修改通过git提交，形成知识演变历史

## 工作流

```
创建笔记 → 编辑内容 → git提交 → GitHub同步
```

## GitHub集成

- **Issues**：用作待办清单和问题追踪
- **Projects**：可视化管理学习进度
- **Pages**：[可选]建立公开数字花园
